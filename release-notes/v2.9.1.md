## Fixes

- **v2.9.0 could quit unexpectedly while a gauge icon showed the window length letter.** [#515](https://github.com/Nanako0129/syrtis/pull/515)

  Drawing the letter went through macOS's text layout, which intermittently stopped Syrtis with an exception; on a test machine it happened once after nearly four hours of normal running. The letter is now drawn directly from the font's glyph, without that layout step, and looks the same as in v2.9.0. If you stay on v2.9.0 for now, turning off "Show window length letter" in the "Menubar icon" section of Settings avoids that drawing path.
