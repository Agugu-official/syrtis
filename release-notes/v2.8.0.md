## Features

- **DeepSeek Harness usage.** [#508](https://github.com/Nanako0129/syrtis/pull/508) — thanks [@kizaki-R](https://github.com/kizaki-R)

  Syrtis now reads DeepSeek Harness (DSH) session logs under `~/.dsh/sessions`. DSH usage appears on its own DeepSeek Harness tab, with the DSH app icon. There is no limits card for DSH.

## Fixes

- **The refresh indicator stopped before the window card had finished loading.** [#509](https://github.com/Nanako0129/syrtis/pull/509)

  The window card reads local usage in a separate step that the indicator at the top right didn't wait for, so the card and its history could fill in a few seconds after the indicator stopped. The indicator now keeps spinning until that step is done.

  If that reading falls more than two minutes behind, the intervals it hasn't reached yet show no bar, and hovering one says "Reading local usage…" instead of showing 0 tokens and "No usage in this interval".
